# API REST Bob

##  Descripción

API_Bob es una API REST  con tematica de bob esponja solo para poder realizar otro proyecto de frontend para consumir esta api en especifica, tambien me ayudara a utilizar un framework de backend(SpringBoot).

---

##  Características

- Arquitectura REST.
- Endpoints para operaciones CRUD.
- Manejo de respuestas en formato JSON.
- Validación de datos.
- Organización por controladores, modelos y rutas.

---

##  Tecnologías utilizadas

- Lenguaje: Java LTS 23
- Framework: SpringBoot
- Base de datos: Mysql
- Git & GitHub

---

##  Estructura del proyecto

Trabajo con una capa arquitectura en capas (Layered Architecture), organizada por módulos o características (Feature-based Package Structure).

Por ejemplo: 

- PedidoEntity → Entidad (Modelo de datos).  
- PedidoRepository → Repositorio (Acceso a datos).
- PedidoService → Lógica de negocio.
- RESTPedidoController → Controlador REST (Expone los endpoints HTTP).

---


##  Uso

Una vez iniciada la API, estará disponible en:

```
http://localhost:PUERTO en mi caso(8080)
```

Los endpoints pueden consumirse mediante herramientas como:

- Postman
- Bruno
- Aplicaciones frontend

---

##  Objetivo

Este proyecto lo hice para poder hacer otro proyecto  que consuma esta api con ayuda de otros Frameworks que lo utilizare para aprender
