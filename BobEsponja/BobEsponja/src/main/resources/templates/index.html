Sobre esta API

Esta API REST permite gestionar la información de Fondo de Bikini: personajes, restaurantes, productos y pedidos. Está construida con Spring Boot y sigue el patrón de arquitectura en capas (Controller, Service, Repository), comunicándose con una base de datos MySQL a través de JPA e Hibernate.

Permite realizar las operaciones básicas de creación, lectura, actualización y borrado (CRUD) sobre cada entidad, además de manejo de errores y limitación.
